# Уведомления в Telegram

Когда клиент нажимает «Я оплатил» или регистрируется новый бизнес, бот пришлёт вам сообщение в Telegram. Всё делается с телефона за 5 минут.

## 1. Создайте бота
1. Откройте Telegram и найдите **@BotFather** (с синей галочкой).
2. Отправьте команду `/newbot`.
3. Придумайте имя (например, «BONUSGO Уведомления») и username, оканчивающийся на `bot` (например, `bonusgo_owner_bot`).
4. BotFather пришлёт **токен** — длинная строка вида `123456789:AAH...`. Скопируйте её (долгое нажатие → «Копировать») и никому не показывайте.
5. Откройте своего бота по ссылке из сообщения и нажмите **Start** — без этого бот не сможет вам писать.

## 2. Узнайте свой chat id
1. Найдите в Telegram **@userinfobot** и нажмите Start.
2. Он ответит сообщением с полем **Id** — это число (например, `123456789`). Скопируйте его.

## 3. Добавьте значения в Render
1. Откройте Render в браузере телефона → ваш сервис BONUSGO → **Environment**.
2. Нажмите **Add Environment Variable** и добавьте две переменные:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHAT_ID` — число из шага 2.
3. Нажмите **Save, rebuild, and deploy** и дождитесь окончания деплоя.

## Проверка
Зарегистрируйте тестовый бизнес — в Telegram придёт «🆕 Новый бизнес: …». Если ничего не пришло: проверьте, что нажали Start у своего бота и что в переменных нет лишних пробелов.
